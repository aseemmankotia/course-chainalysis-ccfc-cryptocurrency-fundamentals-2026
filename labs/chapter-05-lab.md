# Chapter 5 Lab: Address Clustering, Co-Spend Heuristics, and Entity Attribution

**Estimated time:** 20 minutes

## Exercise

Using a public clustering demonstration dataset or explorer, manually group a set of sample addresses that co-spent in the same transaction and reason about why they likely share a common owner

## Key takeaway

Clustering groups addresses by behavior; attribution then labels that cluster with a real-world entity using separate off-chain evidence.
