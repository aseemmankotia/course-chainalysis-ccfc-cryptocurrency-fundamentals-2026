# Chapter 12 Cheat Sheet: Exam Simulation & Time Management

## Time-Box Budget (180-min / 90-question simulation)

| Phase | Time | Purpose |
|---|---|---|
| First pass | ~150-160 min (~2 min/question) | Answer every question once, flag uncertain ones |
| Final review | 10-15 min | Revisit ONLY flagged questions |
| Pacing checkpoint | Every 15-20 questions | Compare elapsed time vs. question count; adjust cap if behind |

**Exam note:** If you're at question 15 past the 30-minute mark, tighten your per-question cap immediately — don't wait until question 45 to react.

## Flagging Decision Matrix

| Elimination progress | Action |
|---|---|
| 3 of 4 options eliminated | Flag — highest-value review target |
| 2 of 4 options eliminated | Flag — worth a second look |
| 0-1 options eliminated | Guess and move on — do NOT flag |

**Review priority order:** 3-eliminated flags first → 2-eliminated flags second. Never re-read all 90 questions in final review — only flagged ones.

## Cross-Domain Scenario Recognition

- Watch for prompts that state a primary requirement AND a secondary constraint (often in the last sentence).
- 3 of 4 answer options typically satisfy the primary requirement but fail the secondary one.
- **Elimination technique:** isolate the secondary constraint, test every option against it specifically, discard any that fail it — regardless of how well they solve the primary ask.

## Elimination Anti-Patterns (Never Use These Heuristics)

- Longest/shortest answer = correct — FALSE, exam writers vary length deliberately
- Most technical-sounding jargon = correct — FALSE, common distractor tactic
- First plausible-sounding option = correct — FALSE, ignores secondary constraints

## Post-Simulation Gap Analysis Workflow

1. Record overall score AND per-domain sub-scores.
2. Identify the sub-category with the lowest score (often cross-domain scenario questions).
3. For cross-domain misses, identify the specific domain PAIRING causing errors (e.g., cost + compliance).
4. Re-study that pairing specifically before re-attempting a simulation.
5. Do not retake a simulation without reviewing explanations for every missed question first.

**Common mistake:** Treating a passing overall score (e.g., 68%) as sufficient while ignoring a failing sub-score (e.g., 40% on cross-domain questions) — real exams can weight these sub-domains enough to cause an overall fail even when total percentage looks passable.
